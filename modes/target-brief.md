# Mode: target-brief -- Outbound Opportunity Brief

Produce a one-page opportunity artifact for an outbound target.

This mode is for founders, small businesses, operators, agencies, creators, or teams that show visible intent plus an execution gap. The goal is to create a specific, useful first touch without doing unpaid consulting.

## Inputs

Accept:

- company/person URL
- social post
- business website
- product page
- community post
- notes from the operator
- observed pain signal

## Research Budget

Keep pre-contact research bounded:

- target time: 15-25 minutes
- produce one page, not a full plan
- use public information only unless the user provides private context
- stop when there is enough evidence for a credible first message

## Target Qualification

Identify:

- visible intent: what suggests they want to move?
- execution gap: what seems missing, manual, stalled, or underbuilt?
- buyer path: who might have authority or influence?
- remote compatibility: can the work be done remotely?
- agent leverage: why can the operator move unusually fast?
- proof match: which backed proof point supports credibility?

Do not assume the target needs help merely because their website or process looks imperfect. Name the evidence.

## Required Output

```markdown
# Target Brief: {Target}

**Verdict:** contact | maybe | monitor | skip
**Buyer hypothesis:**
**Pain signal:**
**Execution gap:**
**Likely offer:** paid trial task | fixed deliverable | implementation-included audit | v0 sprint | automation/internal tool | research/synthesis | other
**Remote fit:**

## What They Appear To Be Trying To Do
- ...

## Where The Gap Might Be
- ...

## Possible First-Customer / Delivery Path
- ...

## Why The Operator Is Credible
- Use only backed proof points.

## Outreach Draft
Short, specific, manual-send only. Mention one observed signal, one plausible helpful outcome, and one low-friction ask.

## Follow-Up Note
One sentence for the tracker: what to do next and when.
```

## Style

- No generic cold pitch.
- No "I can help with anything".
- No invented insider knowledge.
- No full unpaid roadmap.
- Lead with the target's observable situation, not the operator's biography.
